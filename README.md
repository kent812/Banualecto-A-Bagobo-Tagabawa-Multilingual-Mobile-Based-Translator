# Banualecto: A Bagobo Tagabawa Multilingual Mobile-Based Translator

Banualecto is a multilingual mobile-based translator designed to support the Bagobo Tagabawa language, helping preserve and promote indigenous communication through modern technology.

## Getting Started

This project is a Flutter-based mobile application.

### Features
- Multilingual translation
- Support for Bagobo Tagabawa language
- Mobile-friendly interface
- Cultural and language preservation support

### How to Run
1. Install Flutter
2. Run `flutter pub get`
3. Start the app with `flutter run`
